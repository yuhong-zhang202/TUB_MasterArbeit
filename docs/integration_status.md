# Development integration status — 3 November 2026

The private development workspace now has a common run entry and analysis path for OPEN, ALINEA and ALINEA with temporary continuous-green queue protection. A bounded integration check completed one new OPEN and one pure ALINEA run sequentially; an existing queue-protection run was reused after compatibility checks. These checks used M3600/R900, seed17, a 4200-second horizon and a 13% ALINEA occupancy target.

This is a project-status notice, not a new public reproducibility release. The later controller source, exact run cards, raw outputs and independent review records remain in the private thesis repository. The historical replay package supplied here retains its existing scope and commands.

The internal integration review supports the execution and common accounting path at that development condition. Original strict-braking FAIL, rate-diagnostic FAIL and NOT_QUALIFIED records remain. This notice does not establish general safety, rate qualification or a formal treatment effect.

The development work also compared temporary continuous green (A) with extended green in a repeating cycle (B). The proposed main comparison uses A as a deliberately simplified synthetic Queue Override; this does not establish general superiority over other metering designs.

The proposed experiment plan uses four ramp demands (700, 800, 850 and 900 veh/h), a constant 13% occupancy target, and OPEN, ALINEA and ALINEA plus temporary continuous-green Queue Override using the same ten seeds per strategy, for 120 planned runs. The freeway demand remains 3600 veh/h. Exact seed identities, thresholds and detailed acceptance rules are project-level choices requiring review.

Formal experiments have not started. The private formal protocol is a proposed draft, pending user review and unfrozen. It retains unresolved safety/rate qualification limits and explicit failure/censoring decisions. The full main series should wait for feedback from the intermediate presentation. This public notice summarizes private project records; the correspondence and complete protocol are not published here.
